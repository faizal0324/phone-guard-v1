# Penjaga Panggilan

Dua fitur:
1. Penjaga: menolak otomatis panggilan dari nomor yang tidak ada di kontak (atau semua panggilan).
2. Pengalih operator: membuka telepon dengan kode pengalihan (**21*nomor# dan sejenisnya).

## Build APK
1. Buat repository baru di GitHub.
2. Upload seluruh ISI folder ini (app, .github, dan file .kts) lalu Commit.
3. Tab Actions, tunggu build hijau, unduh artifact penjaga-panggilan-apk, install di HP.
